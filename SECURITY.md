# Security

NullSquare Local listens on the loopback interface. Its local HTTP API is single-user. Software running as your OS user can access the workspace. Keep the database in your user profile and restrict access to backups.

Original uploaded files are retained so they can be downloaded again. Use synthetic or redacted evidence when sharing a workspace, screenshot or issue. An external model receives the selected review inputs when you request a review. Store provider credentials in the backend environment.

Contact NullSquare privately at [null@nullsquare.net](mailto:null@nullsquare.net) to report a vulnerability. Ask for a private transfer channel before sending sensitive material. Include the affected revision, operating system, Node.js version, and a minimal redacted reproduction.
