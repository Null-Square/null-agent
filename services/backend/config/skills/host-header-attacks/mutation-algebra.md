# Host Header Mutation Algebra

Test only owner-controlled hosts:

1. canonical `Host`;
2. supplied alternate `Host`;
3. `X-Forwarded-Host` when edge trust is known;
4. absolute-form request target only if observed;
5. canonical host with altered port.

Compare direct response, generated evaluator email/link, and cache status separately. Never send mail to real users. Stop at six requests and two evaluator reset messages.
