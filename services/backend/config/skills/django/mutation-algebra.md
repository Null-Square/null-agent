# Django Mutation Algebra

| Django layer | Mutation |
|---|---|
| URL resolver | canonical route → one named alternate route |
| identity | anonymous → evaluator A → evaluator B/control role |
| object query | owned pk/slug → peer synthetic → nonexistent |
| middleware/decorator | effective order and per-view exemptions |
| settings | active settings module/profile only |
| serialization | form → DRF serializer content type if both are mounted |

Correlate resolver, view, queryset, permission, and response. Do not run migrations, management commands, or settings changes.
