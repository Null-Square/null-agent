# Django Examples

## Framework-Corroborated Proof

- A view is decorated for login but lacks the object permission enforced by its sibling view; evaluator A reads evaluator B's synthetic model object, and ORM/query evidence ties the route to that view.
- A supplied active setting permits an owner-controlled host, and a password-reset email generated for an evaluator embeds that host. Hand the reset-link impact to `host-header-attacks`.
- A template renders an evaluator marker through an explicitly safe-marked value. Hand executable context proof to `xss` or `ssti`.

## Rejections

- `DEBUG=True` appears only in `settings/test.py`.
- The Django admin login is reachable but requires authentication.
- A migration contains historical model fields not used by the deployed route.

Active settings resolution and URL-to-view mapping are mandatory. Never run management commands against production.
