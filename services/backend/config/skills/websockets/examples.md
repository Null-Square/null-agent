# WebSocket Examples

## Protocol Proof

- An unauthenticated handshake joins a supplied private evaluator channel and receives its synthetic canary event; a public channel and nonexistent channel provide controls.
- Evaluator A changes one subscription object id and receives evaluator B's one-time test event.
- An owner-controlled cross-site page opens a credentialed socket because origin is not validated, then performs a harmless evaluator echo action.

## Reject or Defer

- The upgrade succeeds but every private subscription message is denied.
- A ping/pong frame or public broadcast contains no private data.
- One abnormal close occurs without a repeatable semantic effect.

Cap connections at two, messages at ten, and observation at thirty seconds. Do not flood, hold persistent sessions, or subscribe to non-evaluator channels.
