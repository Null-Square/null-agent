# AWS Mutation Algebra

| Axis | Bounded variation | Boundary |
|---|---|---|
| Identity | anonymous versus authorized test user | no AWS credentials |
| Object | one named synthetic key versus nonexistent key | no listing or prefix sweep |
| Distribution | CloudFront URL versus known application origin route | no origin discovery brute force |
| API | one documented stage/method variation | no route spraying |
| Config | active stack versus example module | deployment evidence required |
| Cache | fresh synthetic marker versus cached public asset | no cache poisoning |

The invariant is a public/source observation using evaluator-owned data. Provider control-plane calls are never a mutation.
