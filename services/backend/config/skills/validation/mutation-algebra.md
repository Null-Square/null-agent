# Validation Reduction Algebra

Reduce disputed evidence along independent dimensions:

| Dimension | Reduction |
|---|---|
| request | remove headers/fields until one causal change remains |
| identity | owner, peer synthetic, anonymous/nonexistent controls |
| state | fresh disposable object and authoritative follow-up read |
| timing | minimum repeats and matched control distribution |
| source | active call path and deployed revision |
| evidence | raw record, stable IDs, hashes, and redaction |

Stop when proof is deterministic, disproven, or unsafe to reproduce. Validation may narrow evidence but may not add scope or an exploit chain.
