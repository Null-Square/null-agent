# SSRF Examples

## Attributed callback

A unique public canary URL receives HTTPS from the target's egress 430 ms after the correlated import job; unsubmitted and inert controls receive nothing. Expected disposition: proof.

## Returned marker

The application response contains the evaluator canary's unique body and callback logs identify the server fetch. Expected disposition: proof.

## Browser fetch

The callback occurs only after the evaluator opens a preview and carries the browser user agent/address. Expected disposition: reject.

## DNS reputation check

A shared reputation resolver performs DNS only; no HTTP request or job is created. Expected disposition: reject or lead, not proof.

## No callback infrastructure

The endpoint is blind and internal targets are prohibited. Expected disposition: blocked.
