# Spring Boot Examples

## Framework-Correlated Cases

- A controller method lacks the `@PreAuthorize` rule present on its sibling and evaluator A reads evaluator B's synthetic entity through the active repository query.
- Actuator exposes a named environment property containing the owner-provided canary; health and info endpoints alone remain inventory.
- Jackson binds a server-managed field into a disposable DTO/entity because the effective object-mapper and validation groups permit it.

## False Positives

- An actuator path returns `401`.
- A vulnerable dependency is overridden by the resolved production dependency graph.
- A controller is excluded by the active Spring profile.

Map active profile, security filter chain, request mapping, method authorization, DTO binding, and repository scope. Never invoke shutdown, loggers, heapdump, or configuration-changing actuator endpoints.
