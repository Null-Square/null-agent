# Spring Boot Mutation Algebra

- Profile: effective active profile and resolved property source.
- Mapping: controller method plus exact HTTP verb/path.
- Security: filter chain, matcher, and method annotation.
- Subject/object: evaluator owner, peer synthetic, nonexistent.
- Binding: DTO field and validation group actually selected.
- Repository: scoped query versus direct lookup.
- Actuator: read-only named endpoint/canary only.

Never call shutdown, heapdump, loggers, env mutation, JMX, or administrative operations. Eight evaluator requests maximum.
