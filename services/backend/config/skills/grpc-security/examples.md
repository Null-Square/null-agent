# gRPC Security Examples

## Protocol Proof

- Server reflection lists a service intentionally supplied for testing; that is inventory. Proof occurs only when an unauthenticated unary call returns the private canary field from a named evaluator message.
- Evaluator A changes one protobuf resource id and receives evaluator B's synthetic record; matched owner and nonexistent messages separate IDOR from serialization errors.
- A browser gRPC-Web client sends a method without the metadata interceptor applied to native gRPC, and the server accepts a harmless evaluator action.

## Rejections

- `UNIMPLEMENTED`, `UNKNOWN`, or descriptor output alone is not an authorization flaw.
- A JSON transcoding route and native method both deny access.
- A malformed frame closes the stream without repeatable service impact.

Use supplied descriptors or authorized reflection and at most three messages per method. No streaming load or parser-crash testing.
