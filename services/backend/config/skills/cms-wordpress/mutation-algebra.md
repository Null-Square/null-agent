# WordPress Mutation Algebra

| Axis | Sequence |
|---|---|
| component | core → active plugin → active theme |
| endpoint | observed REST route → registered AJAX action → canonical page |
| capability | anonymous → subscriber evaluator → editor control |
| content | public post → owned draft canary → nonexistent post |
| version proof | loaded code/lock → active asset → readme as weak corroboration |
| multisite | current site only → supplied second evaluator site |

No username harvesting, password attempts, plugin activation, or uploads. Reduce findings to active component, route/action, capability, and synthetic impact.
