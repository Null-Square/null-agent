# Clickjacking Mutation Algebra

| Layer | Variants |
|---|---|
| framing origin | same origin → owner-controlled sibling → unrelated owner test origin |
| frame depth | direct frame → one nested frame |
| browser state | no session → evaluator session |
| target | public page → harmless authenticated preference action |
| defense | CSP `frame-ancestors` → XFO → cookie partition behavior |

Use visible alignment before any transparent overlay. One evaluator click is the maximum state action; stop if framing needs browser-policy bypasses or a real-user workflow.
