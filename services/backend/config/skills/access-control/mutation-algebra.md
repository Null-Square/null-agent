# Access-Control Mutation Algebra

Vary only a decision input while the action and synthetic resource remain fixed.

| Axis | Ordered values |
|---|---|
| subject | owner → peer same role → lower role → other evaluator tenant |
| object | owned canary → peer canary → nonexistent id |
| function | ordinary read → supplied privileged read → harmless privileged action |
| request form | canonical path → documented alternate path → supported method/content type |
| lifecycle | current object → archived evaluator object |

Reduce proof to the smallest subject-object-action tuple. Stop when identities or ownership provenance are missing; never enumerate identifiers.
