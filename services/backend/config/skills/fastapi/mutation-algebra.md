# FastAPI Mutation Algebra

| Binding | Values |
|---|---|
| router | included prefix and dependency graph |
| identity dependency | omitted → evaluator A → evaluator B |
| model field | documented field → one server-managed extra field |
| media type | JSON → supported form/multipart only |
| object | owner canary → peer canary → nonexistent |
| async path | normal completion only; no task-volume mutation |

Tie OpenAPI to the actual route/dependency/model version. Stop before background-task or availability behavior and remove disposable objects.
