# Broad Surface Scan Mutation Algebra

Build the queue from authorized inventory, then widen one bounded dimension:

1. supplied hostname;
2. one DNS name corroborated by certificate or source;
3. observed standard web port;
4. explicitly approved alternate port;
5. one canonical HTTP path per responsive service.

Mutate protocol only when the service advertises it. Deduplicate by resolved address, port, protocol, SNI, and response fingerprint. Stop at the host/port/request cap or when new results repeat existing fingerprints.
