# SOAP Mutation Algebra

- Operation: one supplied WSDL operation at a time.
- Identity: evaluator WS-Security header, omitted header, second evaluator.
- Object: owner canary, peer synthetic id, nonexistent id.
- Envelope: canonical namespace/order and one schema-valid alternate only.
- Timestamp/message id: current versus one bounded replay.
- Transport: documented SOAP action/content type pair.

Cap at three envelopes per operation. No DTD/entity, recursive XML, oversized message, or non-idempotent replay testing.
