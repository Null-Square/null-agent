# Command Injection Examples

## Direct response marker

An authorized diagnostic field normally returns `host reachable`. A candidate containing one POSIX separator returns the unique marker `b1-cmd-74`, while an equal-length inert punctuation control returns the baseline. Retain the raw pair and the observed shell family. Expected disposition: proof.

## Argument injection, not shell injection

A filename beginning with a dash changes an archive tool option and creates a test-only output difference, but shell separators remain literal arguments. Expected disposition: lead for argument injection and handoff for source review; do not claim shell command injection.

## Queue-delay lookalike

Candidate requests and inert controls both finish between 2.5 and 6 seconds, and queue depth rises during the sample. No marker is observed. Expected disposition: reject, because delay is not tied to command syntax.

## Source-only sink

Repository code concatenates a request field into a shell string, but the route is disabled in the deployed configuration and cannot be reached. Expected disposition: lead or blocked with the missing reachability evidence, never a validated finding.

## Safety boundary

The only proposed proof would read environment variables or contact an external host. Expected action: decline that proof and use a page-local marker, workspace marker file, or bounded timing pair instead.
