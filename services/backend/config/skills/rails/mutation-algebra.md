# Rails Mutation Algebra

- Router: active route/engine and verb.
- Callback: effective `before_action` chain and skips.
- Authorization: evaluator A, evaluator B, anonymous.
- Record lookup: policy-scoped collection versus direct `find`.
- Parameters: permitted documented field versus one server-managed candidate.
- Format: HTML versus JSON only when both controller formats are active.
- Signed value: canonical versus one changed consumed field.

Use disposable records and eight requests maximum. Never run console, jobs, migrations, or credential decryption.
