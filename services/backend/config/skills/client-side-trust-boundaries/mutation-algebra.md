# Client-Side Trust Mutation Algebra

Hold the server operation constant and mutate one client-owned decision:

- omitted UI field versus explicitly supplied field;
- displayed price versus server receipt price;
- disabled control versus direct canonical request;
- local role/feature flag versus server-returned authorization state;
- computed identifier versus another supplied evaluator identifier;
- unsigned client metadata versus server-derived metadata.

Proof survives a fresh server read. Stop after six one-field requests and never test real billing, inventory, or entitlements.
