# Information-Disclosure Mutation Algebra

Change the trigger, not the volume:

- valid request versus one malformed field;
- authenticated evaluator versus anonymous control;
- public object versus named private canary;
- production route versus documented error route;
- source artifact active versus example/test artifact;
- redacted response versus raw evidence retained privately.

Stop after the minimum repeat that identifies the disclosed data and its sensitivity. Never enumerate records, download bulk artifacts, or retain unrelated personal/secret values.
