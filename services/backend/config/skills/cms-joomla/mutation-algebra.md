# Joomla Mutation Algebra

- Component: core component → one active contributed component identified in the extension table.
- View: public list → supplied synthetic record → unpublished evaluator record.
- Identity: guest → evaluator registered user → publisher control.
- Route: SEF URL → canonical `option=com_*` form already observed.
- Version evidence: active manifest → asset fingerprint → vendor advisory range.

Use no installation, administrator, upload, or database mutation. Stop when extension activation, content ownership, or version patch level cannot be proven.
