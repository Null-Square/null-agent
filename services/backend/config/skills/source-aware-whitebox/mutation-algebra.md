# Whitebox Correlation Algebra

Walk a single hypothesis across:

1. entry route/event;
2. active middleware/guard;
3. input model and transforms;
4. authorization or validation decision;
5. sink/query/state change;
6. deployed revision;
7. one evaluator runtime control.

Mutate one node or edge to find the minimal missing defense. Dead code, inactive flags, and unmatched deployment versions remain non-runtime leads.
