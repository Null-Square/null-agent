# Web Security Misconfiguration Examples

## Actionable Configuration

- Directory indexing exposes an owner-provided private canary file outside the documented public asset set.
- A production error page returns a synthetic secret from effective configuration; a malformed-request control confirms repeatability without stressing the service.
- An administrative endpoint is anonymously accessible and reveals non-public evaluator configuration, while the login-protected sibling establishes intended policy.

## Inventory Only

- A server/version banner, default favicon, or missing non-applicable header.
- A robots file naming public routes.
- An enabled HTTP method that performs no unauthorized read or state change.

Tie effective configuration to reachable impact and the deployment environment. Do not change server settings, enumerate directories broadly, or invoke management actions.
