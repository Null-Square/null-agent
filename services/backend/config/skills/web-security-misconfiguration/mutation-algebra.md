# Web Misconfiguration Mutation Algebra

Move from configuration to reachability:

1. active deployment/environment;
2. exact server/framework feature;
3. one canonical public route;
4. one safe malformed or anonymous control;
5. named synthetic private canary;
6. intended policy or protected sibling;
7. minimum remediation boundary.

Headers and banners are inventory unless tied to impact. No directory brute force, configuration changes, management actions, or broad file retrieval.
