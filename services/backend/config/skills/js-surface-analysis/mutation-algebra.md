# JavaScript Surface Analysis Algebra

Expand provenance in this order:

1. loaded entry bundle;
2. dynamically loaded chunk observed at runtime;
3. matching source map;
4. route/API/config strings with call-site context;
5. runtime network confirmation.

Classify strings as active, feature-gated, test/example, or unreachable. Deduplicate endpoints by method, normalized URL template, and call site. Never execute discovered hidden actions merely to validate inventory.
