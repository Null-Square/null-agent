# Drupal Mutation Algebra

| Drupal surface | Controlled comparison |
|---|---|
| module/theme | active extension list ↔ lockfile/manifest ↔ public asset |
| entity | owned synthetic node ↔ peer node ↔ nonexistent UUID |
| operation | canonical route ↔ JSON:API/REST view if enabled |
| role | anonymous ↔ supplied authenticated role ↔ editor control |
| state | published test content ↔ unpublished/revision test content |
| environment | active config sync ↔ deployment fingerprint |

Never enable extensions or change permissions. A version match without active deployment and reachable behavior remains a lead.
