# Laravel Examples

## Framework-Linked Cases

- Route-model binding resolves an evaluator B model before a policy check that trusts an attacker-controlled tenant field; evaluator A reads the synthetic canary.
- A fillable/guarded mismatch stores `is_featured=true` on a disposable evaluator record. Route the primitive to `mass-assignment`.
- A signed URL is accepted after a parameter the controller consumes is appended but omitted from signature canonicalization.

## Controls

- `.env.example` contains placeholder credentials only.
- Debug mode appears in local configuration but deployed headers and supplied effective config show production mode.
- An unauthenticated route is intentionally public and returns no private data.

Require active route, middleware, policy/model, and effective configuration evidence. Do not run Artisan commands or clear production caches.
