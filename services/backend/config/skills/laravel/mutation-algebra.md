# Laravel Mutation Algebra

- Route: named route and active middleware group.
- Subject: guest, evaluator A, evaluator B/control role.
- Model: owned binding key, peer synthetic key, nonexistent key.
- Input: validated field versus one server-managed fillable candidate.
- Signature: canonical signed URL versus one changed consumed parameter.
- Environment: resolved production config only; ignore `.env.example`.

Cap at eight evaluator requests, persist only disposable model changes, and never run Artisan, queues, migrations, or cache-clearing commands.
